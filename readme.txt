Fast and lightweight WooCommerce inventory, pricing, and stock audit log manager designed for store efficiency.

== Description ==

**NSK Quick Stock Manager** is a powerful yet lightweight administrative tool built specifically for store owners and developers managing WooCommerce inventories. It streamlines stock adjustments, price updates, and provides a robust audit trail for complete store accountability.

### Key Features
* **Quick Inventory Management:** Easily update stock quantities (with positive/negative relative adjustments), regular prices, and sale prices from a single, streamlined screen.
* **Smart Search:** Instantly filter simple products, variable products, and individual variations using keywords, titles, or exact SKU matching.
* **Variable Product Support:** Cleanly grouped collapsible rows for variable products to manage specific sizes and attributes without clutter.
* **Audit Logs & Tracking:** Automatically logs all inventory modifications, price changes, and SKU updates with timestamps and administrator usernames.
* **Advanced Log Filtering:** Filter historical logs by specific products, keywords, and custom date ranges.
* **Developer Friendly:** Clean code architecture built with security and performance in mind.

Developed and maintained with ❤️ by **NSK DEV**.

== Installation ==

1. Upload the `nsk-quick-stock-manager` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to **NSK Stock Manager** in your WordPress admin sidebar to start managing your inventory.

== Frequently Asked Questions ==

= Does this plugin support WooCommerce variable products? =
Yes! Variable products are fully supported with collapsible variation rows and direct management capabilities.

= Are stock changes tracked? =
Yes, all stock adjustments, price changes, and SKU updates are automatically recorded in the Audit Logs tab along with the administrator's username and custom notes.
